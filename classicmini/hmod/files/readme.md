# EmulationStation

EmulationStation 2.12 (RetroPie fork) as the front end of the NES/SNES Classic, driven by the games hakchi syncs.

Needs the RetroArch (S)NESCE hmod for the libretro cores. Themes are not included: extra themes go on the SD card or USB stick, in `/media/data/emulationstation/themes`.

Hold Select while the console boots to get the stock UI. After two fast crashes in a row it falls back to the stock UI by itself.

Uninstalling removes EmulationStation, its settings and library cache from the NAND but keeps the favourites list. Files on the SD card or USB stick stay.
