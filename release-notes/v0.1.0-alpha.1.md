# ES-PORT v0.1.0-alpha.1

First alpha of the EmulationStation port for the NES and SNES Classic with hakchi. It is meant for testers: expect rough edges.

## What works

- Browses the games hakchi syncs, grouped by system, with covers, descriptions, favorites, collections and themes (es-theme-simple by default).
- Starts games with the console's own emulators: the SNES `canoe` and, on the Famicom, `kachikachi` and the KMFD RetroArch with `fceumm`.
- Suspend points shared with the stock UI: Start resumes, A saves (hold A to overwrite), Select deletes, Down locks.
- Built-in scrapers over HTTPS; what they find survives hakchi syncs.
- Always a way back: hold **Select** while the console boots to get the stock UI, or remove the module with "Remove modules" in hakchi. After two quick crashes in a row the next boot goes to the stock UI by itself.

## Known issues

- No video playback.
- The first boot builds the library, which takes a while on large collections.
- The interface slows down while the scraper runs.
- The NES Classic and the Famicom firmware have been tested much less than the SNES Classic.
- Games need the RetroArch hmod with its cores installed.

## Install

1. Put an SD card or USB stick with a `hakchi` folder in the console; the install needs it for the default theme.
2. Download `emulationstation_classicmini.hmod`, put it in hakchi's `user_mods` folder, select **EmulationStation** under Frontend and sync.
3. If hakchi reports the install as done but EmulationStation does not start, read hakchi's log: without the card or stick the install stops and hakchi still marks the module as installed. Remove it with "Remove modules" and try again.

To report a problem, send `/var/lib/hakchi/emulationstation/home/.emulationstation/es_log.txt` and, after a crash, `/var/lib/hakchi/emulationstation/crash.log`.
